One live stream, personalized ads: DASH Ed.6 Server-Guided Ad Insertion

Both players load the same live stream. At every ad break each one asks livesim2 for its own ad pod, chosen by the viewer's interests, so the two show different ads at the same time. Breaks: · main content: · player: Shaka Player · livesim2 · URL generator · all sessions

How it works
  1. The live MPD has an Alternative-MPD Replace event for each break. Its URL points at livesim2's ad decisioning, /sgai/ads.mpd.
  2. Annex I URL parameters make the player copy sessionId and interests from the MPD URL onto that request.
  3. livesim2 answers with a List MPD: a pod of ads that match the interests, trimmed to the break duration. Without a matching ad there is no pod, and the player keeps showing the AD BREAK countdown slate that livesim2 puts in the main stream during each break.
  4. The player plays the pod, sends impression and quartile beacons, and returns to the live stream. The session monitors below show the decisions and beacons as livesim2 records them.
URL parameters: ?asset= main content, ?breaks= the sgai_ break schedule (default p60:20, a 20 s break at every full UTC minute), ?i0= and ?i1= the viewers' interests.
